# Настройки для сдачи

`.env.example` содержит только имена с пустыми значениями и подсказки по источникам ключей. Нечувствительные локальные значения по умолчанию задаются в Compose и приложении. Поэтому копирование пустого примера по-прежнему позволяет запускать локальный Qwen. Для локальной модели LLM_API_KEY не нужен.

`.env` и `.env.*` исключены из Git. Не добавляйте их принудительно. Для организаторов используйте отдельный `.env.jury`; для облачных LLM выпустите отдельные ключи жюри вместо личных рабочих ключей. Для локального режима достаточно настроек Ollama и созданного командой SERVICE_API_KEY, если требуется авторизация.

1. Установите age по официальной инструкции: https://github.com/FiloSottile/age#installation (`brew install age` на macOS).
2. Скопируйте `.env.example` в `.env.jury` и заполните конфигурацию машины, где будет запуск. Для Ollama в Docker используйте `LLM_PROVIDER=ollama`, `LLM_BASE_URL=http://host.docker.internal:11434/v1`, `LLM_MODEL=travel-qwen:4b`, `LLM_TIMEOUT=180s`. Модель устанавливается отдельно по LOCAL_QWEN.md.
3. Запустите из корня:

```sh
./scripts/encrypt-secrets.sh
```

Скрипт создаёт корневой **бинарный** `secrets.env.age` для публичного получателя организаторов `age1932fu7f70rwyfhaxflyfszz4gf6avxwc95wc0yjwm6zns9tspycqpgdnc0`. ASCII armor не используется, значения не выводятся. Можно явно передать путь к подготовленному файлу: `./scripts/encrypt-secrets.sh /path/to/jury.env`.

Для расшифровки нужен закрытый ключ организаторов. После изменения настроек повторите шифрование. В репозиторий для сдачи включается только `secrets.env.age`, не исходный `.env.jury`. Личный текущий `.env` автоматически не шифруется и не передаётся организаторам. Скрипт не делает commit/push.

В этой ветке secrets.env.age уже подготовлен из отдельного .env.jury: локальный Ollama, пустой ключ LLM и новый отдельный SERVICE_API_KEY. Личные ключи из .env не использовались. Для другой машины или облачного режима подготовьте новые настройки и повторите шифрование.
