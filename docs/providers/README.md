# Описания API провайдеров

Каждый файл описывает одного провайдера: доступ, ручки, параметры, пример конфига, `curl`, фрагмент ответа и ограничения. У внешних API в файлах указаны официальные источники.

Примеры ответов внешних ручек сохранены после запросов 2026-10-25 в `testdata/<провайдер>/`; они подтверждают работу на тот момент. Запросы к отелям не настроены: доступ к ETG / RateHawk требует партнёрского договора. Перепроверить доступные внешние ручки:

```bash
go run ./cmd/smoke
```

Общее для всех:

- **Конфиги запросов:** `configs/examples/<провайдер>.<ручка>.json`.
- **Обязательные поля и ограничения:** `configs/providers/<провайдер>.<ручка>.schema.json`, сгенерированы из Go-структур в `internal/providers/`.
- **Реестр** (адрес, авторизация, лимиты, ручки): `configs/providers.json`.
- **Готовый `*http.Request`** из конфига собирает `providers.Registry.NewHTTPRequest`.
- **Маппинг из `TripRequest`, шпаргалка форматов и общий план:** [PLAN.md](PLAN.md).

Проверено и **не работает** (в коде не используется): Hotellook (404), KudaGo (антибот), OpenTripMap (не приходит письмо при регистрации), Timepad (только с токеном), Amadeus Self-Service (закрыт 17.07.2026).
