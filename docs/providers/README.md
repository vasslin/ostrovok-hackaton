# Описания API провайдеров

Каждый файл описывает одного провайдера так, чтобы по нему можно было написать поход в его ручки: доступ, ручки, параметры, пример конфига, рабочий `curl`, кусок **настоящего** ответа и подводные камни.

Все внешние ручки проверены настоящими запросами 2026-10-25. Полные ответы лежат в `testdata/<провайдер>/`. Перепроверить всё одной командой:

```bash
go run ./cmd/smoke
```

| Файл | Что даёт | Ключ |
|---|---|---|
| [aviasales.md](aviasales.md) | цены на авиабилеты (кэш Aviasales) | `TRAVELPAYOUTS_TOKEN` |
| [travelpayouts_places.md](travelpayouts_places.md) | город → IATA-код, координаты, падежи | не нужен |
| [yandex_rasp.md](yandex_rasp.md) | расписания поездов, самолётов, автобусов, водного транспорта; код города Яндекса | `YANDEX_RASP_API_KEY` |
| [hotels_mock.md](hotels_mock.md) | отели: поиск, тарифы, бронирование (**наш сервис** по контракту ETG, ещё не написан) | `HOTELS_KEY_ID`, `HOTELS_KEY` |
| [wikipedia.md](wikipedia.md) | досуг: достопримечательности рядом с точкой, с описанием и фото | не нужен |
| [nominatim.md](nominatim.md) | геокодинг; музеи, театры, кино по типу места | не нужен |
| [osrm.md](osrm.md) | время и расстояние на машине (трансферы) | не нужен |
| [open_meteo.md](open_meteo.md) | прогноз, история погоды, температура моря | не нужен |
| [cbr.md](cbr.md) | курсы валют ЦБ РФ | не нужен |

Общее для всех:

- **Конфиги запросов:** `configs/examples/<провайдер>.<ручка>.json`.
- **Обязательные поля и ограничения:** `configs/providers/<провайдер>.<ручка>.schema.json`, сгенерированы из Go-структур в `internal/providers/`.
- **Реестр** (адрес, авторизация, лимиты, ручки): `configs/providers.json`.
- **Готовый `*http.Request`** из конфига собирает `providers.Registry.NewHTTPRequest`.
- **Маппинг из `TripRequest`, шпаргалка форматов и общий план:** [PLAN.md](PLAN.md).

Проверено и **не работает** (в коде не используется): Hotellook (404), KudaGo (антибот), OpenTripMap (не приходит письмо при регистрации), Timepad (только с токеном), Amadeus Self-Service (закрыт 17.07.2026).
