# osrm — время в пути на машине (трансферы)

**OSRM, демо-сервер на данных OpenStreetMap.** Время и расстояние на машине между точками: аэропорт или вокзал → отель. Цену трансфера считаем сами (тариф за км × расстояние).

**Статус:** ✓ проверено 2026-10-25, HTTP 200: аэропорт Казани → Кремль, 29 км, ~54 мин. **Ключ не нужен.**

## Правила

- **Демо-сервер:** только лёгкая нагрузка, не чаще 1 запроса в секунду (`rps: 1`).
- **Кэшировать:** у нас на 30 дней — маршрут «аэропорт → отель» не меняется.
- **Для продакшена** поднимают свой OSRM.

## Ручка `route`

`GET https://router.project-osrm.org/route/v1/driving/{coordinates}`

| Параметр | Где | Формат | Пример |
|---|---|---|---|
| `coordinates` | **в пути** | `lon,lat;lon,lat` — **сначала долгота!** | `49.2787,55.6062;49.1062,55.7963` |
| `overview` | query | `false` \| `simplified` \| `full` (геометрия маршрута) | `false` |

Конфиг: `configs/examples/osrm.route.json`. Поле `coordinates` подставляется в путь через тег `path:"coordinates"`.

```bash
curl -s "https://router.project-osrm.org/route/v1/driving/49.2787,55.6062;49.1062,55.7963?overview=false"
```

Ответ (настоящий, сокращён; полный — `testdata/osrm/route.json`):

```json
{
  "code": "Ok",
  "routes": [{"duration": 3268, "distance": 29000.7}],
  "waypoints": [
    {"location": [49.274469, 55.601404], "name": "", "distance": 596.79},
    {"location": [49.105994, 55.796235], "name": "улица Баумана", "distance": 14.82}
  ]
}
```

| Поле | Значение |
|---|---|
| `routes[0].duration` | **секунды** (3268 ≈ 54 мин) |
| `routes[0].distance` | метры |
| `waypoints[].distance` | насколько точка сдвинута до ближайшей дороги, метры |
| `code` | `Ok` или код ошибки (`NoRoute`, `InvalidQuery`) |

## Подводные камни

- **Порядок `lon,lat`** — самая частая ошибка: перепутаешь — получишь точку в другой стране.
- **Пробки не учитываются.** Добавлять запас (например, ×1,3 в часы пик).
- **`overview=full`** даёт геометрию маршрута, чтобы нарисовать трансфер на карте фронтенда.
