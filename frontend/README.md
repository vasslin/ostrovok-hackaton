# О!дин запрос

## Запуск

Нужен Node.js 20+. Установка пакетов и сборка не требуются. HTML-шаблоны интерфейса находятся в `dist/templates.html`, а функции работы с ними в `dist/templates.js`. Для обычного запуска шаблоны загружаются через HTTP.

Для быстрого просмотра без Node.js откройте `dist/standalone.html` в современном браузере. Это автономная демоверсия со встроенной картой и системным шрифтом. После изменения исходников обновите её командой `npm run standalone`. Для разработки и подключения API используйте сервер ниже.

```sh
npm run dev
```

Откройте `http://127.0.0.1:4173`. Команды работают в Windows, macOS и Linux. Для другого порта: `PORT=4174 npm run dev` в macOS/Linux; в PowerShell: `$env:PORT = '4174'`, затем `npm run dev`.

Можно разместить содержимое `dist/` на любом статическом хостинге. Открывать `index.html` двойным щелчком не следует: браузер ограничивает загрузку JS-модулей по `file://`.

## Что сделано

- Чат с сообщениями, быстрыми действиями, ожиданием и обработкой ошибок.
- Форма: город отправления, направление, даты, ночи, гости, возраст детей, бюджет, питомец.
- Географическая карта с локальными контурами стран, точками остановок, связями переездов, приближением и перемещением мышью.
- Подробности остановки: местное время, проживание, прогулки. Подробности переезда: билеты и цены.
- Отдельные вкладки маршрута, билетов и отелей; выбор обновляет полную стоимость.
- Итог поездки, разбивка расходов, подтверждение демозаказа, защита от повторного нажатия.
- Личный кабинет, история бронирований, восстановление последней поездки в браузере.
- На телефоне: переключение «Чат / Маршрут» с сохранением черновика, карточки в одну колонку и нижняя навигация.
- Интерфейс учитывает доступную высоту окна, экранную клавиатуру, вырезы экрана и горизонтальную ориентацию. Основные сенсорные кнопки имеют размер от 44 px, поля ввода от 16 px.
- Формы и подробности прокручиваются отдельно, блокируют фон и возвращают фокус после закрытия. Карту можно масштабировать двумя пальцами; один палец прокручивает страницу.
- Кнопки «Да / Нет» поддерживаются через `actions` в ответе чата; их текст и отправляемое значение задаёт backend.

## Что является демонстрацией

По умолчанию работает `mode: 'demo'`. **Настоящая модель, API провайдеров, авторизация, оплата и реальное бронирование не подключены.** Чат использует небольшой локальный разбор команд; это не AI-агент. Каталог, расписания, цены, названия отелей и условия синтетические. Иллюстрации нарисованы для прототипа и не являются фотографиями отелей. Доплаты за питомцев требуют уточнения и не включены.

Доступны Москва/Казань/Санкт-Петербург как отправление и Анталья/Сочи/Тбилиси/Калининград как направления. Сценарий Антальи от 5 ночей включает 2 ночи в Стамбуле.

Данные демопрофиля, переписка и поездки сохраняются в localStorage только этого браузера. Не вводите реальные чувствительные данные. Реальный backend включается через `dist/config.js`; контракт и ограничения интеграции описаны в `docs/api-contract.md`.


## Проверка

```sh
npm test
npm run check
```

Для браузерных E2E-проверок сначала установите зависимости и браузеры:

```sh
npm ci
npx playwright install chromium webkit
npm run test:mobile
```

В Linux для установки системных библиотек используйте `npx playwright install --with-deps chromium webkit`. При необходимости эта команда запросит права администратора. После установки браузеров остальные команды одинаковы для всех ОС.

Playwright проверяет Chromium на экранах 320, 390, 430, 768, 844 и 1440 px, а также WebKit на телефоне 390 px. Проверяются чат и черновик, уменьшение окна под клавиатуру, вкладки, формы, подробности, карта, история, демобронирование и автономная сборка. Это эмуляция браузеров, проверка на физических iPhone и Android ещё нужна.

При падении проверки отчёт, снимки экрана и трассы сохраняются в `playwright-report/` и `test-results/`. Открыть отчёт: `npx playwright show-report`. Workflow `.github/workflows/frontend.yml` выполняет эти проверки при включённом GitHub Actions.

## Источники географии

Контуры стран: Natural Earth, public domain, масштаб 1:110m. Локальный GeoJSON получен из [natural-earth-vector](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson); сохранены геометрия и название. Карта работает без внешнего картографического API. Линии между городами показывают связи маршрута, а не реальные траектории рейсов.
